**English** · Download **`ChestAddictionCounter.exe`** below and run it. Nothing to install. Coming from Fortnite Chest Counter (LED-N)? Your history and settings are picked up as they are.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory.

**What's new in 1.6.0**
- **Chest Addiction Counter**: a fork of Fortnite Chest Counter by LED-N, with a new look
- **Obsidian interface**: the window is now built with the Obsidian UI (mspaint): sidebar tabs, groupboxes, switches and dropdowns; help texts show up when you hover a setting
- **Report and overlays in the same style**: dark panels, monospace font, purple accent (in game and for OBS)
- **Count ammo boxes, loot cannons and food boxes** in your totals, each with its own switch in Settings (off by default; treasure odds still use real chests only)
- Help links, problem reports and updates now go to this fork; the treasure data keeps coming from the original project

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.
